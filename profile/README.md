# Let agents reason. Let Goa generate.

**Goa is an open-source ecosystem for building Go services and AI agents.**

Define your contracts in Go and generate the code that follows from them. People and coding agents get less repetitive code to write, consistent interfaces to work with, and compiler feedback when contracts change.

**[Explore goa.design](https://goa.design)** · [Develop with a coding agent](https://goa.design/docs/ai-development/)

## Find your starting point

### [Goa](https://github.com/goadesign/goa) · Services and APIs

Generate HTTP, gRPC, and JSON-RPC servers, typed clients, validation, CLI clients, and API specifications from one design. Implement your business logic in Go.

[Service quickstart](https://goa.design/docs/1-goa/quickstart/) · [Documentation](https://goa.design/docs/1-goa/) · [Go reference](https://pkg.go.dev/goa.design/goa/v3/dsl)

### [Goa-AI](https://github.com/goadesign/goa-ai) · AI agents

Build agents with typed tools, structured outputs, and durable workflows. Generate MCP servers or host a tool registry, using the same design-first approach.

[Agent quickstart](https://goa.design/docs/2-goa-ai/quickstart/) · [Documentation](https://goa.design/docs/2-goa-ai/) · [Go reference](https://pkg.go.dev/goa.design/goa-ai)

Start with either framework. Connect them by reusing Goa types and binding agent tools to service methods.

**Working with a coding agent?** [Install the Goa service designer skill](https://goa.design/docs/ai-development/#install-the-skill) to guide service design, generation, implementation, and verification.
